Accessibility Statement

Little Genius Kids aims to follow WCAG 2.2 AA accessibility principles so children, parents, and teachers with diverse abilities can learn comfortably.

Implemented Accessibility Features

  • Skip Navigation & Landmarks: Every page includes a keyboard-accessible "Skip to main content" link and semantic <header>, <nav>, <main>, and <footer> regions.
  • Keyboard Focus & Touch Targets: Clear 3px focus outlines on interactive controls and minimum 44×44px interactive button heights.
  • High-Contrast & Dark Modes: Use the header High-Contrast toggle () or Dark Mode toggle () anytime—preferences save locally.
  • Reduced Motion: Respects prefers-reduced-motion: reduce to minimize animations automatically.
  • Non-Color Feedback: Practice quizzes pair color feedback with explicit icons and text explanations.

Ongoing Improvements & Feedback

We continuously test keyboard navigation, screen-reader labels, and older legacy game canvases for improvements. Report any barrier to support@little-genius-kids.vercel.app.
